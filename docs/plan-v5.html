폴드8용 StandBy 시계·달력 앱

아이폰 스탠바이처럼 폴드8을 가로로 세워 충전하면 시계·달력·날씨·음악 화면이 켜지는 앱을 만든다. 기본 화면은 아이폰 듀오 스탠바이와 같은 “왼쪽 달력 + 오른쪽 정사각 둥근 시계”다.

1차 구현 완료 2026-10-24 · 폴드8 실기기 설치 아이폰 듀오 화면 반영 정사각 시계 · 주황 · 월요일 시작 · 날씨 전체 화면 침대 옆 · 펼친 화면 스택 알람 전 빛 · 움직이면 깨우기 · 사진 · 카메라 피하기
결론
직접 만든 안드로이드 앱 1개로 충분하다. 앱 안에 전체화면 Activity와 화면 보호기(DreamService)를 같이 넣는다.
자동 실행
“가로로 돌리면 실행”은 안드로이드가 막아 둔 동작이다(백그라운드 앱의 화면 띄우기 제한). 대신 충전 중 화면 보호기로 등록하면 충전기에 꽂고 화면이 꺼질 때 시스템이 알아서 띄워 준다. 아이폰 스탠바이도 “충전 + 가로”가 조건이라 체감은 거의 같다.
추천 자세
접은 상태로 커버 화면(1972×1248, 약 1.58:1)을 가로로 세우기. 사진 속 비율(약 1.6:1)과 거의 같다. 펼친 화면·반접기용 레이아웃도 같이 만든다.
스탠바이 기능
시계 · 날씨 · 재생 중 3개 보기를 좌우로 넘긴다. 커버 화면에서는 시계 스타일 3개(달력+아날로그 · 디지털 · 날짜만 크게)를 위아래로, 펼친 화면에서는 오른쪽 반의 위젯 스택(사진 · 시계 · 날씨 · 재생 중)을 위아래로 넘긴다. 음악 컨트롤, 알림 배너, 야간 모드, 알람 전 은은한 빛, 움직이면 깨우기.
기술
Kotlin · Jetpack Compose · Canvas(시계) · java.time(달력) · Jetpack WindowManager(접힘 감지) · NotificationListenerService(음악·알림)
배포·기간
Play 스토어 없이 Android Studio에서 폰에 직접 설치(무선 디버깅). 1차는 끝났고, 남은 일은 항목당 1–4일.
진행 상황
1차 완성, 아이폰 듀오 화면 반영, 침대 옆 기능과 펼친 화면 스택까지 완료. 폴드8(SM-F971N, Android 17)의 커버 화면(가로·세로)과 펼친 화면에서 확인했다. 알람 전 빛과 움직이면 깨우기는 에뮬레이터에서 확인했고, 삼성 시계 알람과 음악 재생 중 화면은 아직 실기기로 보지 않았다.
범위 변경
텐트 자세 자동 실행, 실시간 점수 카드, 스마트홈, 세계 시계, 일정·배터리·알람 위젯은 하지 않기로 했다. 펼친 화면 4칸 대시보드는 오른쪽 위젯 스택으로 바꿨다. 남은 후보는 편집기·색 테마, 추억(몇 년 전 오늘), Flow.

지금 화면 (폴드8 실기기)

폴드8(SM-F971N, Android 17)에서 찍은 실제 앱 화면이다. 시계는 사용자가 보낸 아이폰 듀오 스탠바이 사진(Fri Oct 23)에 맞췄고, 날씨는 Open-Meteo에서 받은 실제 현재 위치 날씨다. 펼친 화면의 사진 카드는 개인 사진이라 여기에는 싣지 않았다.

1. 폴드8에서 어떤 자세로 쓸까

사진 속 아이폰 듀오는 화면이 바깥으로 접히는 구조라 텐트처럼 세워도 화면이 보인다. 폴드8은 안으로 접히므로 텐트 자세에서는 메인 화면이 안쪽에 갇힌다. 그래서 아래 세 가지 자세를 지원하고, 기본값은 커버 화면으로 둔다. 미리보기의 화면 비율은 아래 해상도 그대로다.

2. 아이폰 스탠바이 기능 중 무엇을 넣을까

스탠바이에서 많이 쓰는 기능을 골라 폴드8에서 구현할 방법을 정했다. 아이폰처럼 좌우로 밀면 보기가 바뀌고, 위아래로 밀면 같은 보기 안에서 스타일·위젯이 바뀐다. 미리보기 화면도 좌우로 끌어서 넘겨 볼 수 있다.

3. “가로로 돌리면 실행”은 어떻게 구현하나

안드로이드 10부터 백그라운드에 있는 앱은 마음대로 화면을 띄울 수 없다. 회전 센서를 계속 감시하다가 앱을 여는 방식은 막히거나, 막히지 않더라도 배터리를 상시 잡아먹는다. 그래서 시스템이 이미 제공하는 진입점을 쓴다.

방법동작장단점채택
A. 화면 보호기 (DreamService)설정 › 디스플레이 › 화면 보호기에서 이 앱을 고르고 “충전 중”으로 지정. 충전 중 화면이 꺼질 시간이 되면 시스템이 자동으로 띄운다.권한이 필요 없고 배터리 부담 0. 스탠바이와 동작이 가장 비슷하다. 단, 회전 여부는 조건이 아니므로 세로일 땐 세로 레이아웃을 보여준다.핵심
B. 앱 직접 실행 (Activity)홈 아이콘이나 바로가기로 열면 전체화면 + 화면 켜짐 유지. 가로로 돌리면 레이아웃이 바로 바뀐다.충전기 없이도 쓸 수 있다. 실행은 손으로 해야 한다.핵심
C. 모드 및 루틴 (삼성)“충전 시작” 같은 조건이 되면 “앱 열기”를 실행하는 루틴을 만든다.코딩 없이 자동 실행 조건을 세밀하게 걸 수 있다. 쓸 수 있는 조건(회전·거치 등)은 폴드8의 One UI 버전에서 확인해야 한다.보조
D. 상시 서비스 + 다른 앱 위에 표시 권한포그라운드 서비스가 센서를 감시하다 가로+충전이면 Activity를 띄운다.회전만으로 켜지게 할 수 있지만 상단 알림이 늘 떠 있고 배터리를 쓴다. 삼성 배터리 최적화가 서비스를 죽이는 일도 잦다.비추천

A와 B는 같은 Compose 화면 코드를 공유한다. 화면 하나를 만들어 두 곳에 꽂는 구조다.

DreamService는 Activity가 아니어서 Compose를 바로 붙일 수 없다. LifecycleOwner와 SavedStateRegistryOwner를 직접 구현해 ComposeView에 연결하는 작은 어댑터가 필요하다(알려진 패턴, 반나절 작업). 화면 보호기는 기본적으로 터치하면 꺼지므로 isInteractive = true로 스와이프와 음악 컨트롤을 받는다.

val msm = getSystemService(MediaSessionManager::class.java)
val sessions = msm.getActiveSessions(
    ComponentName(this, NotifListener::class.java))   // 알림 접근 권한 필요

접힘·방향 감지

WindowInfoTracker.getOrCreate(activity)
    .windowLayoutInfo(activity)
    .collect { info ->
        val fold = info.displayFeatures
            .filterIsInstance<FoldingFeature>().firstOrNull()
        posture = when {
            fold?.state == FoldingFeature.State.HALF_OPENED &&
            fold.orientation == FoldingFeature.Orientation.HORIZONTAL -> Posture.Tabletop
            isCoverDisplay(activity) -> Posture.Cover
            else -> Posture.Flat
        }
    }

커버 화면인지 메인 화면인지는 현재 창 크기(가로·세로 dp)로 판별한다. 폴드8에서 실제 값을 찍어 보고 기준을 정한다.

6. 오래 켜 둘 때 필요한 것

  • 번인 방지: 1분마다 전체 화면을 3dp씩 9곳을 돌며 이동. 정적인 흰 숫자가 한 자리에 머물지 않게 한다.
  • 야간 모드: 조도 센서가 3 lx 아래면 모든 요소를 어두운 빨강으로 바꾸고 밝기를 최저로 낮춘다. 센서가 없으면 22시~6시. 설정에서 항상 켜거나 끌 수 있다.
  • 야간 초침: 밤에는 초침을 숨기고 매 프레임 대신 매초만 다시 그려 전력을 아낀다.
  • 화면 켜짐: Activity는 충전 중일 때만 FLAG_KEEP_SCREEN_ON. 배터리로 쓸 땐 시스템 꺼짐 시간을 따른다.
  • 갱신 주기: 날씨 30분(실패하면 5분 뒤 재시도), 일정은 캘린더가 바뀌면 바로 + 5분마다, 음악은 미디어 세션 콜백. 화면이 꺼지면 구독이 모두 멈춘다.
  • 시간 동기화: 날짜는 매분 정각에 다시 확인해 자정과 시간대 변경을 따라간다.
  • 알람 전 은은한 빛: 다음 알람 15분 전부터 호박색 빛과 화면 밝기를 천천히 올린다(처음엔 느리게). 울리는 알람 알림이 떠 있는 동안 최대로 유지하고, 알림 접근이 없으면 알람 1분 뒤에 끈다. 빛이 켜지면 야간 빨강보다 우선한다.
  • 움직이면 깨우기: 밤에만 가속도 센서를 켜고, 1분 동안 움직임(0.35 m/s² 넘는 흔들림)도 터치도 없으면 검은 덮개 93%와 밝기 0으로 거의 끈다.

8. 폰에 설치하는 방법

  1. 폴드8: 설정 › 휴대전화 정보 › 소프트웨어 정보 › 빌드번호 7번 탭 → 개발자 옵션 활성화.
  2. 개발자 옵션 › 무선 디버깅 켜기. Mac과 같은 와이파이에 연결.
  3. Android Studio에서 ~/Projects/fold-standby를 열고 Device Manager › Pair Devices Using Wi-Fi에서 QR로 페어링.
  4. Run 버튼으로 설치. 터미널에서는 ./gradlew installDebug (JAVA_HOME은 Android Studio 내장 JDK).
  5. 앱 목록에 아이콘 두 개가 생긴다. StandBy 설정에서 “화면 보호기 설정 열기” → Fold StandBy 선택 → 시작 조건 “충전 중”.
  6. 같은 화면에서 캘린더·대략적 위치·알림 접근을 허용하고, 언어·강조색·야간 모드를 고른다. StandBy 아이콘은 충전기 없이 바로 화면을 연다.

이 Mac에서는 adb 서버가 그냥 켜지지 않고 멈춘다. ADB_LIBUSB=1 adb start-server로 켜면 동작한다.

삼성 설정 메뉴 이름은 One UI 버전에 따라 조금 다를 수 있다. 화면 보호기 메뉴가 보이지 않으면 설정 검색창에서 “화면 보호기”로 찾는다.

9. 미리 알아둘 위험

  • 커버 화면에서 화면 보호기가 뜨는지: 접은 상태로 충전할 때 삼성이 커버 화면에 화면 보호기를 띄우는지 실기기로 먼저 확인해야 한다. M1에서 가장 먼저 검증한다. 안 되면 B(직접 실행) + C(루틴)로 간다.
  • Always On Display와의 충돌: AOD가 켜져 있으면 화면 보호기 대신 AOD가 뜰 수 있다. 우선순위를 실기기로 확인.
  • 알림 접근 권한 제한: 스토어 밖에서 받은 APK 파일은 안드로이드의 “제한된 설정” 때문에 알림 접근을 바로 켤 수 없다. Android Studio로 설치하면 대개 문제없지만, 막히면 앱 정보 › 제한된 설정 허용을 먼저 눌러야 한다.
  • 화면 보호기 안의 접힘 감지: WindowManager의 접힘 정보는 Activity 기준이라 DreamService 안에서는 제한될 수 있다. 그 경우 창 크기만으로 레이아웃을 고른다.
  • 거치대: 커버 화면을 가로로 세울 받침이 필요하다. 무선 충전 스탠드를 쓰면 “충전 + 세움”이 한 번에 해결된다.

10. 기본값으로 정한 것

열려 있던 질문은 “기본값으로 진행”으로 정리했다. 바꾸고 싶으면 대부분 설정 화면에서 바로 바꿀 수 있다.

범위텐트 자동 실행·점수 카드·스마트홈·세계 시계·날씨 외 위젯은 하지 않는다(사용자 결정).
자동 실행 조건충전 중 화면 보호기. 회전만으로 켜지는 방법 D는 넣지 않았다.
날씨와 일정날씨는 대략적 위치, 권한이 없으면 서울. 일정(아래 띠)은 폰에 연결된 모든 캘린더.
표시 언어사진처럼 영어(“Sat Oct”)가 기본, 설정에서 한국어로 전환. 주 시작은 아이폰 듀오 사진처럼 월요일(설정에서 일요일). 시간 형식은 폰 설정(12/24시간)을 따른다. 공휴일 표시는 2차.
침대 옆 시계알람 전 빛과 움직이면 깨우기는 기본으로 켜 두었다. 설정에서 따로 끌 수 있다.
